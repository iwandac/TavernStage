# 上游资料归档

`github/` 原样保存初始 ST 基线的 GitHub 首页、翻译、模板、机器人配置和工作流；不是 TavernStage 的生效配置或支持承诺。其中的相对链接按原始 `.github/` 位置编写，查阅完整原始上下文请访问[固定上游版本](https://github.com/SillyTavern/SillyTavern/tree/8172dcd0ee672d3cd9a5e5f7af134f91a45cd2b8/.github)。

移动而非继续启用这些文件，是为了避免 ST 专用机器人、npm 发布及容器发布在派生仓库触发。当前生效配置只有仓库根目录 `.github/` 中经过审查的 TavernStage 配置；项目说明以根 `README.md` 为准。上游源码与许可证没有搬迁或重写。

升级时审查上游新增/修改的 `.github/` 文件：相关参考更新到这里，不直接恢复到活动工作流目录。不能仅凭 Git 合并无冲突就认定自动化安全。
